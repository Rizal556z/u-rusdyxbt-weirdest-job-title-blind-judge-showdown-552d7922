Entry for the [make.fun](https://make.fun) competition
[Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922).

`main.py` (pure Python standard library, no network, no randomness) writes one
job title — 60 characters at most — to `/output/entry.txt`:

> **Professional Mourner for Abandoned Shopping Carts**

Run it with:

```sh
python3 main.py
```
